**Star Shepherd** — the stars have lost their way. Pilot a shepherd ship through the dark, gather lost star-sprites (they trail behind you like a comet tail), and fly them into the beacon ring to bring them home. Carry more at once for a bigger combo, but the heavier you are, the slower you fly — and the void wisps are hunting. Six waves, a ticking clock, three lives, and a pulse shockwave when things get close.

## Run it

```sh
# Serve the game/ folder with any static server, then open game/index.html
python3 -m http.server 8080 --directory game
# or: npx serve game
```

Move with the mouse or WASD / arrow keys. Space (or click) fires a pulse that shoves wisps away. P pauses, M mutes, Enter starts and restarts.
